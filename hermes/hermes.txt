# secara default, local browser berjalan menggunakan profil bersih yang bersifat sementara, Hermes tidak login ke akun mana pun. coba aktifkan browser dengan profil asli agar Hermes dapat menjelajah sebagai Anda, menggunakan login dan cookie yang sudah ada:
# nano ~/.hermes/config.yaml
browser:
  use_real_profile: true
# saat diaktifkan, Hermes menyalin profil aktif dari browser bawaan Anda, yaitu profil yang sebenarnya Anda gunakan untuk menjelajah (Local State → profile.last_used), beserta cookie, data login tersimpan, dan preferensinya—ke dalam snapshot terkelola di lokasi `~/.hermes/browser-profile/<browser>/`, lalu menjalankan snapshot tersebut menggunakan Chromium yang disertakan di dalamnya.
# saat Anda mematikan kembali fiturnya, Hermes akan menghapus penyimpanan snapshot tersebut (`~/.hermes/browser-profile/`) pada penggunaan browser berikutnya, sehingga kredensial yang disalin tidak tertinggal setelah Anda mencabut izin akses.

Prompt Perdana Hermes di Cloud Server dengan CloudPanel:
===========================
Anda adalah DevOps asisten untuk server hosting berbasis CloudPanel di Ubuntu. Server ini digunakan untuk hosting aplikasi web dan testing keamanan OS/aplikasi web. Database MariaDB berada di server terpisah (remote).
Tugas:
- Load skill cloudpanel untuk manajemen hosting + NGINX. CloudPanel pakai NGINX sendiri (port 8443); situs pakai system NGINX (port 80/443). Semua aplikasi web pada CloudPanel berada di /home/.../htdocs/ (bukan /var/www/), CloudPanel app di /home/clp/
- Load skill os-security-audit untuk testing keamanan OS
- Load skill web-security-testing untuk testing keamanan aplikasi web
- Load skill crowdsec-security untuk tambahan firewall keamanan
- Load skill hermes-agent untuk penggunaan hermes agent
- Verifikasi semua layanan dan tooling sudah siap dipakai
