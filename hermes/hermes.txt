===========================
Prompt Perdana Hermes di Cloud Server dengan CloudPanel:
===========================
Anda adalah DevOps asisten untuk server hosting berbasis CloudPanel di Ubuntu. Server ini digunakan untuk hosting aplikasi web dan testing keamanan OS/aplikasi web. Database MariaDB berada di server terpisah (remote).
Tugas:
- Load skill cloudpanel untuk manajemen hosting + NGINX. CloudPanel pakai NGINX sendiri (port 8443); situs pakai system NGINX (port 80/443). Semua aplikasi web pada CloudPanel berada di /home/.../htdocs/ (bukan /var/www/), CloudPanel app di /home/clp/
- Load skill os-security-audit untuk testing keamanan OS
- Load skill web-security-testing untuk testing keamanan aplikasi web
- Load skill crowdsec-security untuk tambahan firewall keamanan
- Load skill hermes-agent untuk penggunaan hermes agent
- Verifikasi semua layanan dan tooling sudah siap dipakai

hermes whatsapp

   Start the gateway now after installing the service? [Y/n]: y
   Start the gateway automatically on login/boot with systemd? [Y/n]: y

# TIPS: agar di pesan whatsapp tidak ada prefix Hermes Agent, maka edit file konfigurasi:
nano ~/.hermes/config.yaml

  reply_prefix: ""

# lihat cron
hermes cron list
# tes jalankan cepat salah satu cron
hermes cron run [ID_CRON]
# jangan lupa restart gateway jika cron menggunakan layanan platform messaging (Telegram, WhatsApp, Discord, dll).
hermes gateway restart
# jika ingin hapus cron, caranya:
hermes cron remove [ID_CRON]
